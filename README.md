# Trifke — portfolio

Statican sajt. Otvori `index.html` u pretrazivacu ili hostuj folder kao GitHub Pages.

## Fajlovi
- `index.html` — ceo sajt
- `support.js` — runtime potreban za prikaz
- `image-slot.js` — komponenta za slike
- `*.png` — fotografija, mockupi, grain tekstura

## GitHub Pages
1. Napravi repo i ubaci sadrzaj ovog foldera u root.
2. Settings → Pages → Source: `main` / `root`.
